# Sound credits

Every recorded sound in `app/assets/sfx/` is cut from the ESC-50 dataset (https://github.com/karolpiczak/ESC-50).
Only clips whose original Freesound recording is CC0 (public domain) were used, so no attribution is required. We credit them anyway.
The music, beeps, voices and a few small effects are synthesized in `app/js/audio.js`.

To recut them: download the ESC-50 clips listed below into `raw/`, then run `python3 tools/cut-sounds.py` (needs numpy, scipy, ffmpeg).
